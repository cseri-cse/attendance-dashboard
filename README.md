# 연구실 근태 · 연차 소진 대시보드

가치업(가치업/Gachieup) 앱에서 export한 근태기록 엑셀을 업로드하면, 브라우저에서 바로 파싱해서
- 학기 누적 연차 소진 현황 (배정연차 대비 초과 여부)
- 월별 출석률

을 자동으로 계산·시각화하는 정적 웹페이지입니다. lab-seats, equipment-rental과 동일하게 **GitHub Pages + 순수 프론트엔드(서버 없음)** 구조입니다.

## 배포 방법 (cseri-cse 조직 기준)

1. 이 저장소를 `cseri-cse` 조직 아래 새 리포지토리로 생성 (예: `attendance-dashboard`)
2. `index.html`을 저장소 루트에 커밋 & 푸시
3. 저장소 **Settings → Pages → Source**를 `main` 브랜치 / `/ (root)`로 설정
4. 몇 분 후 `https://cseri-cse.github.io/attendance-dashboard/` 에서 접속 가능

## 사용 방법

1. 페이지 접속 후 가치업 export 엑셀 파일(.xlsx)을 드래그 앤 드롭
2. 시트(탭) 1개 = 연구원 1명, 각 행의 "비고" 열에 "연차" / "반차" / "출장" 텍스트가 있으면 자동 인식
3. 사람별 과정(석사/박사) 드롭다운으로 배정연차(11일/12일) 조정 가능
4. 우측 상단 "엑셀로 다운로드"로 계산 결과를 다시 xlsx로 저장 가능

## 데이터 처리 관련

파일은 서버로 전송되지 않고 **브라우저 메모리에서만 처리**됩니다. 새로고침하면 업로드 내용과 설정(과정 지정 등)은 초기화됩니다 — 누적 저장이 필요해지면 기존 Apps Script + Google Sheets 백엔드를 연결하는 작업을 추가할 수 있습니다.

## 컬럼 인식 로직 (수정 시 참고)

`index.html` 내 `<script>` 블록의 `handleFile()` 함수에서 시트별로 "날짜" / "이름" / "출근" / "비고" 컬럼을 헤더 텍스트로 자동 탐지합니다. 실제 export 파일의 비고 표기(예: "반차 (오전)")가 다르게 나오면 `findCol`, `note.includes(...)` 조건부만 맞춰 수정하면 됩니다.
